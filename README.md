
# My Personal AI Agent

A simple personal AI assistant built using Node.js, Express.js, and Ollama.

## Features
- Chat with a local AI model
- Powered by Llama 3.2
- Simple web-based chat interface
- Runs locally on your computer

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Ollama

## How to Run

1. Install Node.js and Ollama.
2. Download the Llama 3.2 model:
   `ollama pull llama3.2`
3. Open the backend folder:
   `cd backend`
4. Install dependencies:
   `npm install`
5. Start the server:
   `node server.js`
6. Open http://localhost:5000 in your browser.
